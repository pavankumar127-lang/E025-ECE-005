# ECE-005 Prepaid IoT SIM Pooled Data Pack Engine

## Project Description
A Python-based application that manages prepaid IoT SIM cards, data pack purchases, pooled data usage, account balances, and data overage calculations.

## Technologies Used
- Python
- VS Code
- CSV for data storage
- Unittest for testing

## Project Setup

### 1. Prerequisites
- Python 3 installed
- VS Code (recommended)

### 2. Download the Project
Clone the GitHub repository:

```bash
git clone https://github.com/pavankumar127-lang/ECE-005-IoT-SIM-Data-Pack-Engine.git
```

Open the project folder in VS Code.

### 3. Run the Application

Open the terminal in the project folder and execute:

```bash
python main.py
```

The application will execute the IoT SIM pooled data pack operations.

### 4. Run the Unit Tests

Execute the following command in the terminal:

```bash
python -m unittest discover -v
```

This discovers and executes the available unit tests.

The tests verify:
- Account registration
- SIM registration

- Data pack creation and purchase
- SIM suspension and resumption
- Data usage processing
- Pooled data calculations
- Account status and validation rules

### 5. Expected Result

The application should execute successfully, and the unit tests should display their results.

## Project Outcome
Successfully developed a Python-based prepaid IoT SIM pooled data management engine with account management, SIM management, data pack purchasing, pooled usage tracking, overage calculations, and automated testing.
